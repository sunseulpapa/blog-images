# blog-images
GitHub Pages는 `gh-pages` 브랜치에서 배포된다. 파일을 올릴 때는 `main`에 커밋한 뒤 `git push origin main main:gh-pages`로 두 브랜치에 같이 올린다. 주소는 https://sunseulpapa.github.io/blog-images/경로 이고, 올린 뒤 1~2분 지나야 열린다.

- `reviews/orders/`: '써보고 고르기' 리뷰 글에 넣는 사용자 주문 내역 캡처 (사람 얼굴은 가려서 올림)

- `fix/`: 2026-11-24 만료된 이미지(Canva·Figma·Firecrawl 임시 주소) 대신 다시 만든 카드. `fix/index.html`이 글별 교체표.

**이 저장소의 이미지는 네이버 블로그 글에 직접 연결돼 있다. 저장소를 삭제·비공개로 바꾸면 블로그 이미지가 모두 깨진다. 삭제·비공개 금지.**
